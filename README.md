# Мир Ио — расширенная версия

Симуляция живого мира: планета, физика, мозг Ижикевича,
трансформер-подсознание, корпорация Ио, гипотезы и сны.

## Запуск на ПК
    pip install numpy requests
    python main.py --console

## Команды
    прожить N, мир, статус, вопрос ..., обучить N, скачать N,
    сон, диагностика, гипотеза, бросить, сохранить, выход

## Сборка APK
Запушьте файлы на GitHub — workflow .github/workflows/build.yml
соберёт APK в Actions (15-25 минут), заберите io-apk из Artifacts.

## Сохранение
Команда `сохранить` пишет save.json рядом с программой;
при следующем запуске мир продолжается с того же дня.
